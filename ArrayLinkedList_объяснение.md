# Двусвязный список на массиве: объяснение кода

## Главная идея

`ArrayLinkedList<T>` — двусвязный список, элементы которого лежат в динамическом массиве `slots_`. Соседи элемента задаются **индексами** `prev` и `next`, а не указателями. Значение `-1` означает, что соседа нет.

Порядок ячеек массива может отличаться от порядка элементов списка. В примере программы значения размещаются так: `slots_[0] = 1`, `slots_[1] = 3`, `slots_[2] = 2`. Но связи образуют цепочку индексов `0 → 2 → 1`, поэтому выводится `1 2 3`.

## Заголовки и шаблон

```cpp
#include <iostream>
#include <stdexcept>
#include <utility>

template <class T>
class ArrayLinkedList {
```

- `<iostream>` нужен для `std::cout`.
- `<stdexcept>` предоставляет исключение `std::out_of_range`.
- `<utility>` предоставляет `std::move`.
- `T` — тип значения. В `ArrayLinkedList<int>` вместо `T` используется `int`.
- Пока в классе не встретилось `public:`, его содержимое закрыто для внешнего кода.

## Ячейка и поля класса

```cpp
struct Slot {
    T value{};
    int prev = -1;
    int next = -1;
    bool used = false;
};
Slot* slots_ = nullptr;
int capacity_ = 0, size_ = 0, head_ = -1, tail_ = -1, free_ = -1;
```

`value` хранит значение. Запись `{}` инициализирует его значением по умолчанию: для `int` это `0`. `prev` и `next` — индексы соседей. `used` показывает, занята ли ячейка.

`slots_` указывает на динамический массив ячеек. В начале массива нет, поэтому он равен `nullptr`.

| Поле | Что хранит |
|---|---|
| `capacity_` | Число выделенных ячеек массива |
| `size_` | Число элементов списка |
| `head_` | Индекс первого элемента |
| `tail_` | Индекс последнего элемента |
| `free_` | Индекс первой свободной ячейки |

Важно различать `capacity_` и `size_`: массив может содержать четыре ячейки, а список — два элемента.

Поле `next` имеет два назначения. У занятой ячейки оно ведёт к следующему элементу списка. У свободной ячейки — к следующему свободному месту. Поэтому существуют две цепочки: **цепочка элементов** и **цепочка свободных ячеек**.

## `grow()` — увеличение массива

```cpp
void grow() {
    int old_capacity = capacity_;
    int new_capacity = capacity_ ? capacity_ * 2 : 4;
    Slot* next = new Slot[new_capacity];
    for (int i = 0; i < old_capacity; ++i) next[i] = std::move(slots_[i]);
    delete[] slots_;
    slots_ = next;
    capacity_ = new_capacity;
    for (int i = new_capacity - 1; i >= old_capacity; --i) {
        slots_[i].next = free_;
        free_ = i;
    }
}
```

1. `old_capacity` запоминает прежнюю вместимость.
2. Условный оператор `capacity_ ? capacity_ * 2 : 4` выбирает новую: при первом вызове 4, позднее вдвое больше старой. Вместимости растут как `4, 8, 16, ...`.
3. `new Slot[new_capacity]` выделяет новый массив. Локальная переменная `next` — указатель на него; её не следует путать с полем `Slot::next`.
4. Цикл переносит старые ячейки **под прежние индексы**. Например, ячейка `2` остаётся ячейкой `2`, и её связи продолжают работать. `std::move` разрешает перемещающее присваивание, если оно доступно; сам по себе данные он не переносит.
5. `delete[] slots_` освобождает прежний массив. Удаление `nullptr` при первом вызове допустимо.
6. `slots_ = next` и `capacity_ = new_capacity` переключают список на новый массив.
7. Последний цикл добавляет новые ячейки в начало свободной цепочки. При первом расширении она становится такой: `free_ → 0 → 1 → 2 → 3 → -1`.

## `acquire()` — получение ячейки

```cpp
int acquire(const T& value) {
    if (free_ == -1) grow();
    int id = free_;
    free_ = slots_[id].next;
    slots_[id].value = value;
    slots_[id].next = -1;
    slots_[id].prev = -1;
    slots_[id].used = true;
    ++size_;
    return id;
}
```

`const T& value` принимает значение по ссылке без копирования аргумента и не разрешает его менять через эту ссылку. Если свободных ячеек нет (`free_ == -1`), вызывается `grow()`. Затем `id` получает индекс первой свободной ячейки, а `free_` передвигается на следующую. В выбранную ячейку записывается значение, связи сбрасываются, `used` становится `true`, размер увеличивается и возвращается индекс.

Этот метод только **подготавливает** ячейку. Связи с соседями устанавливает вызывающий метод вставки.

## `check()` — проверка индекса

```cpp
void check(int id) const {
    if (id < 0 || id >= capacity_ || !slots_[id].used)
        throw std::out_of_range("invalid list index");
}
```

Индекс неправильный, если он отрицателен, выходит за пределы массива или указывает на свободную ячейку. `||` означает «или» и вычисляется слева направо с остановкой на первом истинном условии. Поэтому при `id < 0` обращения `slots_[id]` не будет. `const` после списка параметров означает, что метод не изменяет список. При ошибке выбрасывается исключение.

## Создание и уничтожение списка

```cpp
public:
ArrayLinkedList() = default;
ArrayLinkedList(const ArrayLinkedList&) = delete;
ArrayLinkedList& operator=(const ArrayLinkedList&) = delete;
~ArrayLinkedList() { delete[] slots_; }
```

`public:` открывает методы для внешнего кода. `= default` оставляет обычный конструктор; поля получают начальные значения из объявлений. Две строки с `= delete` запрещают копирование и копирующее присваивание. Иначе автоматическое копирование перенесло бы только адрес массива, и два объекта попытались бы освободить одну память. Деструктор `~ArrayLinkedList()` освобождает массив при уничтожении объекта.

## `push_back()` и `insert_after()`

```cpp
int push_back(const T& value) { return insert_after(tail_, value); }
```

Добавить в конец означает вставить после последнего элемента `tail_`. Если список пуст, `tail_ == -1`.

```cpp
int insert_after(int position, const T& value) {
    if (position == -1 && size_ != 0) throw std::out_of_range("position required");
    if (position != -1) check(position);
    int id = acquire(value);
    if (position == -1) {
        head_ = tail_ = id;
    } else {
        int following = slots_[position].next;
        slots_[id].prev = position;
        slots_[id].next = following;
        slots_[position].next = id;
        if (following == -1) tail_ = id;
        else slots_[following].prev = id;
    }
    return id;
}
```

`position` — индекс элемента, после которого вставляем новый. `-1` разрешён только при пустом списке; иначе позиция должна пройти проверку `check()`. `acquire(value)` выделяет ячейку и возвращает её индекс `id`.

Если список пуст, новый элемент одновременно первый и последний: `head_ = tail_ = id`. Иначе запоминается прежний следующий элемент `following`. Схема меняется так:

```text
До:     position ⇄ following
После:  position ⇄ id ⇄ following
```

Новый элемент ссылается назад на `position` и вперёд на `following`. У `position` поле `next` меняется на `id`. Если `following == -1`, новый элемент стал последним и обновляется `tail_`; иначе у `following` исправляется поле `prev`. Метод возвращает индекс вставленного элемента.

## `insert_before()` — вставка перед элементом

```cpp
int insert_before(int position, const T& value) {
    check(position);
    int before = slots_[position].prev;
    int id = acquire(value);
    slots_[id].next = position;
    slots_[id].prev = before;
    slots_[position].prev = id;
    if (before == -1) head_ = id;
    else slots_[before].next = id;
    return id;
}
```

Позиция обязательно должна существовать. `before` запоминает прежнего предыдущего соседа, `acquire()` даёт новую ячейку. Схема меняется так:

```text
До:     before ⇄ position
После:  before ⇄ id ⇄ position
```

Новый элемент связывается с обоими соседями, а `position.prev` указывает на него. Если прежнего предыдущего элемента не было, вставка произошла перед головой и обновляется `head_`. Иначе обновляется `before.next`. Возвращается индекс нового элемента.

## `erase()` — удаление элемента

```cpp
void erase(int id) {
    check(id);
    int before = slots_[id].prev, after = slots_[id].next;
    if (before == -1) head_ = after;
    else slots_[before].next = after;
    if (after == -1) tail_ = before;
    else slots_[after].prev = before;
    slots_[id].used = false;
    slots_[id].prev = -1;
    slots_[id].next = free_;
    free_ = id;
    --size_;
}
```

Сначала проверяется индекс и запоминаются соседи `before` и `after`. Затем они соединяются напрямую:

```text
До:     before ⇄ id ⇄ after
После:  before ⇄ after
```

Если `before == -1`, удаляется первый элемент и `head_` становится равен `after`; иначе исправляется `before.next`. Если `after == -1`, удаляется последний элемент и `tail_` становится равен `before`; иначе исправляется `after.prev`.

Если удаляется единственный элемент, оба соседа равны `-1`, поэтому `head_` и `tail_` тоже станут `-1`. Затем ячейка помечается свободной, добавляется в начало свободной цепочки и `size_` уменьшается. Остальные ячейки массива при удалении не сдвигаются.

Сам объект `T` внутри свободной ячейки при `erase()` не уничтожается; его значение перезапишется при повторном использовании ячейки.

## `find()`, `print()` и `size()`

```cpp
int find(const T& value) const {
    for (int i = head_; i != -1; i = slots_[i].next)
        if (slots_[i].value == value) return i;
    return -1;
}
```

Поиск начинается с `head_`. После каждой проверки `i` получает индекс следующего элемента через `slots_[i].next`. При совпадении возвращается **индекс ячейки**, а при отсутствии значения — `-1`. Массив подряд не просматривается: порядок задают связи.

```cpp
void print() const {
    for (int i = head_; i != -1; i = slots_[i].next)
        std::cout << slots_[i].value << ' ';
    std::cout << '\n';
}
int size() const { return size_; }
```

`print()` проходит по той же цепочке и выводит значения с пробелом, затем переводит строку. `size()` сразу возвращает сохранённое количество элементов. Оба метода отмечены `const`, поскольку не изменяют список.

## Пошаговая работа `main()`

```cpp
ArrayLinkedList<int> list;
int one = list.push_back(1);
int three = list.insert_after(one, 3);
int two = list.insert_before(three, 2);
list.print();
std::cout << "index of 2: " << list.find(2) << '\n';
list.erase(two);
list.print();
list.erase(one); list.erase(three);
std::cout << "size after erase: " << list.size() << '\n';
```

1. Создаётся пустой список `int`: `size_ = capacity_ = 0`, а `head_ = tail_ = free_ = -1`.
2. `push_back(1)` впервые вызывает `grow()`, создаёт 4 ячейки и помещает `1` в ячейку `0`. Поэтому `one == 0`. Свободная цепочка: `1 → 2 → 3 → -1`.
3. `insert_after(one, 3)` берёт ячейку `1`, поэтому `three == 1`. Список: `0 ⇄ 1`, значения: `1 ⇄ 3`.
4. `insert_before(three, 2)` берёт ячейку `2`, поэтому `two == 2`. Список по индексам: `0 ⇄ 2 ⇄ 1`; по значениям: `1 ⇄ 2 ⇄ 3`.
5. Первый `print()` выводит `1 2 3`. `find(2)` возвращает индекс `2`. Совпадение индекса и значения здесь случайно: значение `3` находится под индексом `1`.
6. `erase(two)` освобождает ячейку `2`; её соседи `0` и `1` связываются напрямую. Второй `print()` выводит `1 3`.
7. `erase(one)` и `erase(three)` удаляют остальные элементы. `size()` возвращает `0`. При выходе из `main()` деструктор освобождает массив.

Состояние после первых трёх вставок:

| Индекс | `value` | `prev` | `next` | `used` |
|---:|---:|---:|---:|---|
| 0 | 1 | -1 | 2 | `true` |
| 1 | 3 | 2 | -1 | `true` |
| 2 | 2 | 0 | 1 | `true` |
| 3 | 0 | -1 | -1 | `false` |

При этом `head_ = 0`, `tail_ = 1`, `free_ = 3`, `size_ = 3`.

Вывод программы (в строках со списком после последнего числа также есть пробел):

```text
1 2 3 
index of 2: 2
1 3 
size after erase: 0
```

## Сложность

Если операции над самим `T` считать постоянными по времени:

| Операция | Время | Причина |
|---|---|---|
| `size()` | `O(1)` | Возвращает поле |
| `erase(id)` | `O(1)` | Исправляет несколько связей |
| Вставка без расширения | `O(1)` | Берёт первую свободную ячейку |
| Вставка с расширением | `O(capacity_)` | Переносит массив |
| Вставка в длинной серии операций | Амортизированно `O(1)` | Вместимость удваивается редко |
| `find()` | `O(size_)` | Может пройти весь список |
| `print()` | `O(size_)` | Проходит все элементы |

## Что полезно сказать преподавателю

> Здесь двусвязный список хранится в массиве. У каждой занятой ячейки есть индексы предыдущего и следующего элементов. Начало и конец списка задают `head_` и `tail_`. Свободные ячейки объединены в отдельную цепочку, начало которой хранит `free_`. При вставке берётся свободная ячейка и исправляются связи соседей. При удалении соседи соединяются напрямую, а ячейка возвращается в свободную цепочку. При расширении ячейки переносятся под теми же индексами. Поэтому порядок элементов может отличаться от порядка ячеек массива. Поиск требует `O(n)`, а вставка без расширения и удаление по известному индексу — `O(1)`.

Важный вопрос: **можно ли использовать старый индекс после удаления?** Нет. Освобождённая ячейка может позднее достаться другому значению; прежний индекс тогда будет обозначать уже новый элемент.

Ограничение реализации: тип `T` должен поддерживать создание значения по умолчанию и нужные операции присваивания. Для `find()` требуется `==`, а для `print()` — вывод через `<<`. Также код не полностью защищён от исключений сложных типов: если присваивание значения в `acquire()` выбросит исключение, ячейка уже будет исключена из свободной цепочки. В показанном примере с `int` такой ситуации нет.
