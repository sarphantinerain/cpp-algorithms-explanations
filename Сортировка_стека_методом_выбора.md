# Сортировка стека методом выбора

Здесь реализована **сортировка стека методом выбора**: алгоритм каждый раз находит максимальный из оставшихся элементов и переносит его в результирующий стек.

Максимумы складываются в порядке `7, 4, 4, 1, -2`. Но стек выдаёт элементы в обратном порядке, поэтому при извлечении получится:

```text
-2 1 4 4 7
```

Разберём каждую часть и проследим работу программы.

## 1. Что такое стек

**Стек работает по принципу LIFO: последний добавленный элемент извлекается первым.**

Представь стопку тарелок: новую кладут сверху и снимают тоже сверху.

Основные операции:

| Операция | Действие |
|---|---|
| `Create()` | Создать пустой стек |
| `Empty()` | Проверить, пуст ли стек |
| `Push(value)` | Положить значение на вершину |
| `Pop()` | Снять значение с вершины и вернуть его |

Например:

```cpp
Push(4);
Push(7);
Push(1);
```

Стек будет выглядеть так:

```text
Вершина → 1
          7
          4
```

Последовательные вызовы `Pop()` вернут `1`, затем `7`, затем `4`.

В дальнейшем будем изображать стеки **снизу вверх**:

```text
[4, 7, 1] ← вершина справа
```

## 3. Класс `Stack`

```cpp
// Only Create, Empty, Push and Pop are used by the sorting routine.
```

Комментарий сообщает об ограничении: алгоритм работает со стеком только через указанные операции.

В самой функции сортировки используются `Create`, `Push` и `Pop`. Проверка `Empty` применяется при выводе результата.

### Внутреннее хранение

```cpp
class Stack {
    std::stack<int> data_;
```

Объявляется класс `Stack`.

Внутри него находится стандартный стек целых чисел:

```cpp
std::stack<int> data_;
```

Поле закрытое, поскольку у `class` доступ по умолчанию — `private`.

Поэтому функция сортировки не может напрямую обращаться к содержимому `data_`.

```cpp
public:
```

Далее идут доступные снаружи методы.

### Создание стека

```cpp
static Stack Create() { return {}; }
```

Метод возвращает новый пустой стек.

- `static` означает, что его можно вызвать через имя класса;
- `return {};` создаёт возвращаемый объект `Stack` с начальной инициализацией.

Использование:

```cpp
Stack input = Stack::Create();
```

Внутренний `std::stack<int>` при этом создаётся пустым.

### Проверка пустоты

```cpp
bool Empty() const { return data_.empty(); }
```

Возвращает:

- `true`, если стек пуст;
- `false`, если в нём есть элементы.

`const` означает, что метод не изменяет объект.

### Добавление элемента

```cpp
void Push(int value) { data_.push(value); }
```

Добавляет `value` на вершину внутреннего стека.

Метод ничего не возвращает, поэтому тип результата — `void`.

### Извлечение элемента

```cpp
int Pop() {
    int value = data_.top();
    data_.pop();
    return value;
}
```

В исходном коде это записано одной строкой, но действий три.

```cpp
int value = data_.top();
```

Получаем значение на вершине и сохраняем его.

`top()` сам по себе ничего не удаляет.

```cpp
data_.pop();
```

Удаляем верхний элемент.

У стандартного `std::stack` метод `pop()` ничего не возвращает. Поэтому значение пришлось предварительно получить через `top()`.

```cpp
return value;
```

Возвращаем сохранённое число.

**Вызывать этот `Pop()` для пустого стека нельзя:** проверка пустоты внутри метода отсутствует.

## 4. Общая идея сортировки

Функция использует два стека:

- `input` — элементы, которые ещё нужно отсортировать;
- `selected` — уже выбранные максимумы и временно перекладываемые элементы.

Каждый проход состоит из трёх действий:

1. Переложить оставшиеся элементы из `input` в `selected`, одновременно найдя максимум.
2. Вернуть их обратно в `input`, пропустив ровно одно вхождение максимума.
3. Положить найденный максимум в `selected`.

После этого неотсортированных элементов становится на один меньше.

Особенность решения: **стек `selected` одновременно хранит результат и используется как временный стек.** Уже отсортированная часть лежит внизу, а временные элементы помещаются поверх неё.

## 5. Заголовок функции

```cpp
Stack selection_sort(Stack input, std::size_t count) {
```

Функция принимает:

```cpp
Stack input
```

Стек по значению. Это отдельный объект, с которым функция может работать, извлекая из него элементы.

```cpp
std::size_t count
```

Количество элементов в стеке.

`std::size_t` — беззнаковый целочисленный тип, используемый для размеров и количества элементов.

```cpp
Stack
```

Перед именем функции — тип возвращаемого результата: функция возвращает стек.

**Для правильной сортировки `count` должен точно совпадать с количеством элементов в `input`.**

## 6. Создание результирующего стека

```cpp
Stack selected = Stack::Create();
```

Создаём пустой стек, в который будем складывать выбранные максимумы.

Например, по ходу работы он будет принимать состояния:

```text
[7]
[7, 4]
[7, 4, 4]
[7, 4, 4, 1]
[7, 4, 4, 1, -2]
```

Напоминаю: вершина справа.

## 7. Внешний цикл

```cpp
for (std::size_t remaining = count; remaining > 0; --remaining) {
```

Переменная `remaining` показывает количество ещё не отсортированных элементов.

Для пяти чисел она принимает значения:

```text
5, 4, 3, 2, 1
```

После каждого прохода один максимум остаётся в результирующем стеке, поэтому количество оставшихся элементов уменьшается.

Разберём части цикла:

```cpp
std::size_t remaining = count;
```

Изначально не отсортирован ни один элемент.

```cpp
remaining > 0;
```

Продолжаем, пока остаются элементы.

```cpp
--remaining
```

После прохода уменьшаем их число на один.

## 8. Подготовка к поиску максимума

```cpp
int maximum = 0;
bool first = true;
```

```cpp
int maximum = 0;
```

Переменная для максимального значения текущего прохода.

Но начальный `0` **не считается уже найденным максимумом**. Это важно для отрицательных чисел.

```cpp
bool first = true;
```

Флаг показывает, что ни одного числа пока не просмотрено.

Первое извлечённое число станет начальным максимумом независимо от его знака.

Например, для чисел:

```text
-8, -3, -12
```

максимум должен быть `-3`, а не `0`. Именно флаг `first` обеспечивает правильное поведение.

## 9. Первый внутренний цикл: поиск максимума

```cpp
for (std::size_t i = 0; i < remaining; ++i) {
```

Цикл обрабатывает ровно `remaining` элементов.

```cpp
int value = input.Pop();
```

Снимаем верхний элемент из исходного стека.

```cpp
if (first || value > maximum) maximum = value;
```

Обновляем максимум, если:

- это первое просмотренное число;
- либо текущее число больше найденного максимума.

Оператор `||` означает логическое «или».

Для первого элемента `first == true`, поэтому он обязательно записывается в `maximum`.

```cpp
first = false;
```

Первый элемент уже обработан. Дальше сравниваем числа с текущим максимумом.

```cpp
selected.Push(value);
```

Сохраняем извлечённое число во вспомогательном стеке.

Это необходимо, потому что `Pop()` удалил его из `input`.

После завершения этого цикла:

- все неотсортированные элементы временно находятся в `selected`;
- переменная `maximum` содержит их максимум;
- `input` пуст;
- ранее выбранные максимумы по-прежнему лежат внизу `selected`.

## 10. Подготовка к удалению одного максимума

```cpp
bool skipped = false;
```

Флаг означает: «Одно вхождение максимума уже пропущено?»

Зачем он нужен? Максимальное значение может встречаться несколько раз.

Например:

```text
4, 4, 1
```

На этом проходе нужно выбрать **только одну четвёрку**. Вторая должна вернуться в `input` и участвовать в следующем проходе.

## 11. Второй внутренний цикл: возвращение элементов

```cpp
for (std::size_t i = 0; i < remaining; ++i) {
```

Извлекаем ровно столько элементов, сколько временно положили в `selected`.

Это важно: ниже временной части могут находиться уже выбранные максимумы. Их цикл не затронет.

```cpp
int value = selected.Pop();
```

Берём очередное временно сохранённое число.

```cpp
if (!skipped && value == maximum) skipped = true;
```

Если одновременно:

- максимум ещё не пропускали;
- текущее число равно максимуму;

то отмечаем его пропущенным.

`!skipped` означает «не `skipped`».

В этой ветке число **не возвращается** в `input`.

```cpp
else input.Push(value);
```

Все остальные числа возвращаем в исходный стек.

Сюда попадут и повторные максимумы, потому что после первого пропуска:

```cpp
skipped == true
```

и условие `!skipped` станет ложным.

## 12. Добавление выбранного максимума

```cpp
selected.Push(maximum);
```

После обратного перекладывания в `selected` остались только ранее выбранные максимумы.

Теперь поверх них кладём максимум текущего прохода.

Например:

```text
До прохода:    [7]
Новый максимум: 4
После прохода: [7, 4]
```

Каждый следующий выбранный максимум не больше предыдущего. Поэтому внизу будут большие значения, а ближе к вершине — маленькие.

```cpp
return selected;
```

После завершения внешнего цикла возвращаем готовый стек.

## 13. Разбор `main()`

```cpp
int main() {
```

Точка входа в программу.

```cpp
const std::vector<int> values{4, -2, 7, 4, 1};
```

Создаём вектор исходных значений.

`const` означает, что после создания этот вектор нельзя изменять обычными операциями изменения.

```cpp
Stack input = Stack::Create();
```

Создаём пустой стек.

```cpp
for (int value : values) input.Push(value);
```

Это цикл по элементам контейнера.

Последовательно в стек добавляются:

```text
4
-2
7
4
1
```

Получается:

```text
input: [4, -2, 7, 4, 1]
                      ↑ вершина
```

Поэтому первым из стека будет извлечено число `1`.

### Вызов сортировки

```cpp
Stack sorted = selection_sort(std::move(input), values.size());
```

```cpp
values.size()
```

Возвращает количество исходных чисел — `5`.

```cpp
std::move(input)
```

Позволяет передать содержимое `input` в параметр функции через перемещение.

Без `std::move`, при передаче этого объекта по значению, создавалась бы его копия. Здесь исходный стек дальше не нужен, поэтому допускается перемещение.

Точнее: `std::move` сам ничего не переносит, а позволяет использовать перемещающий конструктор.

После перемещения не следует рассчитывать на прежнее содержимое `input`. В этой программе к нему больше не обращаются.

Результат сортировки сохраняется в `sorted`.

### Вывод

```cpp
std::cout << "Ascending pop order: ";
```

Выводим подпись: «Порядок извлечения по возрастанию».

```cpp
while (!sorted.Empty())
    std::cout << sorted.Pop() << ' ';
```

Пока стек не пуст:

1. снимаем верхний элемент;
2. выводим его;
3. выводим пробел.

Проверка `Empty()` обеспечивает, что `Pop()` не вызывается для пустого стека.

```cpp
std::cout << '\n';
```

Переходим на новую строку.

После вывода стек `sorted` пуст: все элементы из него извлечены.

## 14. Первый проход подробно

Начальное состояние, вершина справа:

```text
input:    [4, -2, 7, 4, 1]
selected: []
remaining = 5
```

### Перекладываем и ищем максимум

| Извлечено из `input` | `maximum` после проверки | `selected`, вершина справа |
|---:|---:|---|
| 1 | 1 | `[1]` |
| 4 | 4 | `[1, 4]` |
| 7 | 7 | `[1, 4, 7]` |
| -2 | 7 | `[1, 4, 7, -2]` |
| 4 | 7 | `[1, 4, 7, -2, 4]` |

Теперь:

```text
input:    []
selected: [1, 4, 7, -2, 4]
maximum = 7
```

### Возвращаем элементы, пропуская одну семёрку

Из `selected` числа выходят в порядке:

```text
4, -2, 7, 4, 1
```

Действия:

| Число | Действие | `input`, вершина справа |
|---:|---|---|
| 4 | Вернуть | `[4]` |
| -2 | Вернуть | `[4, -2]` |
| 7 | Пропустить, установить `skipped = true` | `[4, -2]` |
| 4 | Вернуть | `[4, -2, 4]` |
| 1 | Вернуть | `[4, -2, 4, 1]` |

После этого:

```cpp
selected.Push(maximum);
```

Получаем:

```text
input:    [4, -2, 4, 1]
selected: [7]
```

Один элемент окончательно выбран.

## 15. Все проходы

Все стеки в таблице записаны снизу вверх, вершина справа.

| Проход | `remaining` | Найденный максимум | `input` после прохода | `selected` после прохода |
|---|---:|---:|---|---|
| 1 | 5 | 7 | `[4, -2, 4, 1]` | `[7]` |
| 2 | 4 | 4 | `[-2, 4, 1]` | `[7, 4]` |
| 3 | 3 | 4 | `[-2, 1]` | `[7, 4, 4]` |
| 4 | 2 | 1 | `[-2]` | `[7, 4, 4, 1]` |
| 5 | 1 | -2 | `[]` | `[7, 4, 4, 1, -2]` |

Из готового стека сначала извлекается верхний элемент `-2`, затем `1` и так далее.

Полный вывод:

```text
Ascending pop order: -2 1 4 4 7
```

## 16. Почему алгоритм работает правильно

Перед каждым проходом выполняются два условия:

1. В `input` находятся все ещё не выбранные элементы.
2. В `selected` находятся уже выбранные максимумы: снизу вверх они расположены по невозрастанию.

В ходе прохода:

- находим максимум среди оставшихся;
- возвращаем все элементы, кроме одного вхождения максимума;
- кладём этот максимум поверх предыдущих.

Предыдущие максимумы не меньше нового, поэтому порядок в `selected` сохраняется.

На каждом проходе количество элементов в `input` уменьшается на один. После `count` проходов все элементы находятся в `selected`, а извлечение с вершины даёт порядок по возрастанию.

**Повторы сохраняются**, потому что за проход выбирается только одно вхождение максимума.

## 17. Сложность

Пусть исходное количество элементов — `n`.

На первом проходе дважды обрабатываем `n` элементов, на втором — `n - 1`, затем `n - 2` и так далее:

```text
2n + 2(n - 1) + ... + 2
```

Поскольку:

```text
1 + 2 + ... + n = n(n + 1) / 2
```

время работы составляет:

```text
Θ(n²)
```

Эта оценка сохраняется даже для уже отсортированных данных: алгоритм всё равно выполняет все проходы.

Дополнительная память:

```text
O(n)
```

Она нужна для стека `selected`. Отдельный третий стек для временного хранения не создаётся.

## 18. Что могут спросить на защите

**Почему ищем максимум, если вывод нужен по возрастанию?**

Потому что стек извлекает элементы в обратном порядке. Сначала кладём большие, затем меньшие; меньшие оказываются сверху.

**Зачем `first`, если `maximum` уже равен нулю?**

Чтобы корректно обрабатывать отрицательные числа. Первое извлечённое значение обязательно становится начальным максимумом.

**Зачем `skipped`?**

Чтобы исключить из исходного стека ровно один максимум за проход, сохранив остальные одинаковые значения.

**Почему не теряется уже отсортированная часть `selected`?**

Первый цикл кладёт поверх неё ровно `remaining` временных элементов. Второй снимает ровно `remaining` элементов, поэтому нижняя часть остаётся нетронутой.

**Зачем передавать `count`?**

В заданном интерфейсе нет операции получения размера стека. Здесь количество известно из исходного вектора и передаётся отдельно.

**Что будет при неправильном `count`?**

Если он больше фактического размера, программа попытается извлечь элемент из пустого стека, что приводит к неопределённому поведению. Если меньше — функция обработает только часть элементов и не вернёт полный отсортированный набор.

## 19. Как рассказать преподавателю

> Я реализовал сортировку стека методом выбора, используя только операции создания, добавления и извлечения элементов.
>
> На каждом проходе я перекладываю все оставшиеся элементы из исходного стека в результирующий и одновременно нахожу максимум. Затем перекладываю их обратно, пропуская ровно одно вхождение максимума. Для этого использую флаг `skipped`. После этого кладу найденный максимум в результирующий стек.
>
> Результирующий стек также служит временным хранилищем: временные элементы находятся поверх уже выбранных максимумов. Я снимаю ровно столько элементов, сколько временно добавил, поэтому готовая часть не затрагивается.
>
> Максимумы выбираются от большего к меньшему. Поскольку стек выдаёт элементы в обратном порядке, при извлечении получается последовательность по возрастанию. Время работы — `O(n²)`, дополнительная память — `O(n)`.

Самая важная последовательность для понимания одного прохода: **переложить и найти максимум → вернуть всё, кроме одного максимума → положить максимум в результат**.
